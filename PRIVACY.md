# Privacy

DOAJ Discovery MCP is designed to be a stateless discovery service.

- No user account or personal profile is required.
- Query text and manuscript abstracts are not intentionally persisted in application logs.
- The optional local cache stores public DOAJ responses only and can be disabled with `ENABLE_CACHE=false`.
- The service does not sell data or add advertising trackers.
- The hosting provider may still record standard operational data such as request timing, status, IP address, and error information. Review the provider's privacy terms for its retention rules.
- Do not submit confidential, unpublished, personal, or otherwise sensitive text to a public deployment.

The service sends search requests to the public DOAJ API. DOAJ's own policies and terms apply to that upstream request.

This project is independent and unofficial. It is not affiliated with, endorsed by, sponsored by, or operated by DOAJ.

For questions or privacy concerns, open an issue in the project repository.
