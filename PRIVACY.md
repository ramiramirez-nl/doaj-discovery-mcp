# Privacy

DOAJ Discovery MCP is a public, read-only discovery service.

## Application Behavior

- No user account or personal profile is required.
- Query text and manuscript abstracts are not intentionally persisted in application logs.
- Production caching is disabled.
- A self-hosted installation can enable a best-effort cache containing public DOAJ responses.
- The service has no advertising trackers and does not sell data.

## Providers

Requests pass through Google Cloud and are transformed into requests to the public DOAJ API. Those
providers can process standard operational data such as IP address, request timing, status, and
upstream query metadata under their own policies and retention rules.

## Sensitive Content

Do not submit confidential, unpublished, personal, or otherwise sensitive manuscript content.
Results and metadata should be verified at DOAJ and the journal's own website.

This project is independent and unofficial. It is not affiliated with, endorsed by, sponsored by,
or operated by DOAJ.

For privacy questions, open a
[GitHub issue](https://github.com/ramiramirez-nl/doaj-discovery-mcp/issues) without including
sensitive text.
