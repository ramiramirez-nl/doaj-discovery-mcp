# Contributing

Thanks for helping improve DOAJ Discovery MCP.

## Before Opening A Pull Request

1. Keep the service read-only and discovery-only.
2. Preserve the independence notice and avoid implying DOAJ endorsement.
3. Add or update focused tests for behavior changes.
4. Use Node.js 24 or newer and install with `npm ci`.
5. Run `npm run check` and build the Docker image.
6. Do not commit `.env`, credentials, cache files, or unpublished user content.

## Pull Requests

Explain the user-facing reason for the change, note any configuration changes, and include verification results. Keep changes small enough to review.
